# LOCAL Stage 1 非学习验收规格

本规格在首次运行新增验收前登记。依据 LOCAL-v2.0（2026-09-17）第
25.2 章，补齐现有测试缺少的独立轨迹参考、交叉事件和感知恢复记录。
它不改变科研模型、配置、训练场景采样律或任何生产代码；工程 PHASE
B5.1、论文方法 B5 和 LOCAL Stage 1 是不同的编号体系。

## 固定案例、参考和容差

| 案例 | 独立参考及预登记容差 |
| --- | --- |
| 三维恒速，10 s | 初始 u=0.8、yaw=0.4、pitch=0.2，实际角率为零；p(t)=p0+ut(cos(yaw)cos(pitch), sin(yaw)cos(pitch), -sin(pitch))；位置绝对误差 <=1e-11 m |
| 稳态恒转，10 s | 初始实际 yaw rate=指令=0.1 rad/s，u=0.8，pitch=0；独立圆弧公式；RK2 中点位置积分全局误差界 u T omega² h²/24=8.3334e-6 m，登记 <=1e-5 m；yaw <=1e-12 rad |
| 一阶响应与变化率限制，10 s | 初始 u=0.3、实际角率0，指令(0.9,0.1,-0.04)；用不调用生产导数/旋转函数的标量 Eq.(6)-(8) RHS，SciPy DOP853 rtol=1e-11、atol=1e-13；RK2位置 <=2e-3 m、角度 <=2e-4 rad、surge <=5e-4 m/s、角率 <=2e-4 rad/s |
| 头对头 / 交叉 | 稳态直行与严格 CV 障碍；独立标量二次根计算物理半径首次接触；事件时间 <=1e-10 s，接触净间距 <=1e-10 m；检查最早事件后无额外推进 |
| 空间边界 / pitch边界 / 成功 | 固定稳态初值，独立线性阈值时间；误差 <=1e-10 s；边界使用完整物理包络，角度不 clip |
| 固定短 timeout | 仅命名测试夹具把计划时域及成本时域同时设为2步；生产 YAML 和训练时域1000不变；0.4 s 后终止且不能再 step |
| 净间距边界 | 固定横向偏移生成0.25、0.5、0.75 m无碰撞净间距，误差 <=1e-10 m；near-miss仅为无碰撞且真实净间距<0.5 m；验证额外裕量不参与真实碰撞 |
| range进入 / 离开 | 固定CV轨迹分别越过25 m中心检测边界；无dropout夹具只隔离几何，不改变生产传感配置 |
| FOV离开 / 返回 | 实际世界先稳态正yaw转动，再按原一阶响应负yaw转动；tick0和30可见、tick5不可见；不重置世界 |
| 遮挡 / 解除 | 真实CV横穿视线的物理包络球；tick0和15目标1可见，tick5遮挡；没有替换传感/跟踪生产实现 |
| dropout / 恢复 | 初次真实有噪声检测后，命名夹具3步dropout=1，再恢复dropout=0；不改变项目文件 |
| 延迟1 / 2 tick | 检测发生时间与到达时间分别保留；只处理已到达检测；这些是接口验收，不是正式退化/OOD实验 |

每个缺测间隔独立核对 m'=F m、P'=F P F^T+Q，其中 F、Q 由标量
CV 积分块直接构造，不调用生产预测函数；均值/协方差绝对容差1e-11，
相对容差0。恢复时核对最近测量发生时间确实更新。

## 复用已有科学断言

坐标正交/符号、CV/Q积分和半群、Joseph独立高斯条件协方差、概率模型内
采样误差、扫掠包含、整数tick延迟重放、有限时域失败尾项、真实验证器、
真速度/未来信息毒化边界、非法动作、成功/timeout/external truncation、
一秒合法warm-up及100个生成场景warm-up，由原tests及外置Phase A测试
真实重跑，不为本规格重复实现。

## 日志及禁止范围

`scripts/run_stage1_acceptance.py --output-dir <新目录>`保存一份结构化结果、
控制节点轨迹、首次事件表、传感/估计同步记录和真实命令。所有案例为
明确命名的非学习固定验收场景；空障碍解析场景不属于TRAIN_SCENARIO_V1，
其1—4个障碍范围和初始重叠诊断保持原样。

不导入RL agent、不创建Replay、不执行梯度或策略训练、不做throughput
measurement、不生成摘要清单或交接包。测试预期和容差不得看到结果后改变。
L1失败保留案例及根因，重跑相关检查；三轮同类核心失败暂停独立复核。
当前脚本只验收Stage 1，不实现Stage 2训练入口或可达性训练任务。
